## 本次更新

- **推理引擎升级到 llama.cpp b11558**：真机端 16 个引擎库按 `armv8.2-a+dotprod` 从源码重编（官方预编译包是 ARMv8.6，在骁龙 855/865/870/888 上会执行到 `stlur`/`smmla` 直接 SIGILL），PC / 模拟器端同步升级到 `b11558`
- **修复真机 GPU(OpenCL) 装载链路**：三个装载期根因全部修掉（引擎子进程 linker namespace 拿不到 `/vendor/lib64`、旧的 ICD loader 认不出平台、OpenCL 目标版本 3.0 与驱动 2.0 不匹配），平台与设备可正常枚举；部分机型仍受驱动编译器缺陷影响，这类机型请用 CPU 档
- **dock 栏固定在底部**：键盘弹出时不再收起，角色 / 新建角色 / 设置常驻
- **真机设置页不再提供手写启动参数**：启动参数固定由 App 按档位装配（CPU `-ngl 0 -dev none` / GPU `-ngl 999 -dev GPUOpenCL` / NPU `--device HTP0`）
- 修复 NPU 档「有设备但会话打不开」（DSP 侧 `0x80000406`）：`ADSP_LIBRARY_PATH` 必须是**单个目录**，且 skel 需实物落在该目录（含 `cdsp/` 子目录）—— 修正后魅族 21 Pro 的 NPU 档可直接使用
- 引擎适配增强：按机型自动选择 Hexagon HTP 版本与 DSP 域，NPU 会话失败时自动降档重试（v79→v75→v73），仍失败才回退 GPU(OpenCL) → CPU
- 修复 NPU 降档重试的诊断日志把「上一轮强制 vX 失败」误写成新档位的问题
- 模型目录支持任意合规 `.gguf` 自动识别与加载，不再依赖内置清单
- 角色推理状态按角色隔离：甲正在输出时切到乙，乙界面不再误显示「正在思考中」；跨角色发送时提示「暂不支持同步会话」
- 设置页打赏入口内置微信 / 支付宝收款码，打赏横幅与弹窗改用随包矢量奶茶图标（模拟器字库缺 🧋 字形）
- 版本号 1.0.1 升至 1.0.2（versionCode 3）

## 推理设备支持

- 高通骁龙处理器（含 Adreno GPU、Hexagon NPU）：部分支持CPU、GPU、NPU三档推理，优先顺序为NPU→GPU→CPU。引擎起不来时 App 会说明原因并自动回退到下一档。实测魅族 21 Pro（SM8650，4B-Q4）：NPU 档 prompt 430 / 生成 11.5 tokens/s，GPU 档 prompt 91 / 生成 7.6，CPU 档 prompt 15 / 生成 8.1 —— 三档均能正常启动，NPU 综合最快；红米 K40（888，DSP 只有 v68）NPU 档提示后回退、CPU 档约 5～6 tokens/s。
- 其它处理器：仅支持 CPU 推理，速度较慢

## 安装信息

- 模型路径：/storage/emulated/0/{{APP}}/{{MODEL}}
- 需要「所有文件访问权限」（Android 11 及以上）
- versionCode {{VC}}
- 安装前若已装同名旧版且版本号更高，需先卸载；卸载不会删除模型目录，但会清空 App 内的角色与对话数据

## 推荐模型

- 下载页：https://pan.quark.cn/s/14ce44be5923
- 建议选 Q4_0 及以上量化：Q4_0 约 2.4 GB、Q4_K_M 约 2.5 GB（项目实测在用）、Q5_K_M 约 2.9 GB、Q6_K 约 3.2 GB
- 6 至 8 GB 内存机型选 Q4_0 或 Q4_K_M，8 GB 以上可上 Q5_K_M 或 Q6_K
- 下载后放进 /storage/emulated/0/{{APP}}/{{MODEL}}，再回设置页点「重新扫描」
- 更低的 Q3_K、Q2_K、IQ1 至 IQ2 系列不建议：长人设容易掉设定、复读变多
